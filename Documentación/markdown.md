# ¿Qué es Markdown?

Markdown es un lenguaje de marcado ligero que se usa para dar formato a texto de manera simple usando caracteres especiales. 
La idea es que el texto sea fácil de leer y escribir en su forma original, pero que luego pueda convertirse en formatos más complejos como HTML.

Se usa mucho para documentación, archivos README de proyectos, apuntes y publicaciones en plataformas de desarrollo.

## Sintaxis básica

### Títulos
Los títulos se crean usando el símbolo `#`. Cuantos más `#`, más pequeño es el título.

# Título 1
## Título 2
### Título 3
