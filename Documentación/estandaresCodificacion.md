# Estándares de codificación

## Para escribir las variables va a regir el formato Camel case.
Camel case es una convención de escritura para frases o nombres compuestos que elimina espacios y guiones, capitalizando la primera letra de cada palabra a excepción de la primera. (Ejemplo: camelCase)

## Las propiedades marcadas no utilizables en esta entrega son:

* `display:flex`
* `display:grid`
* `position`
* `margin`
* `padding`
* `border`
* `<script>`

## Las propiedades que se podrán usar:

* **display:inline**
* **display:block**
* **display:inline:block**
* **max wight 1500px**
* **border-collapse: collapse;**
* **Podemos uar :root {} para declarar variables que vamos a utilizar varias veces en todas las paginas.**
